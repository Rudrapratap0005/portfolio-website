## ✨ Features

- **⚡ Blazing Fast Performance:** Powered by Vite & React 18, ensuring rapid sub-second load times.
- **🎨 Glassmorphic & Premium UI:** Designed with custom CSS tokens, modern gradients, and deep dark-mode aesthetics.
- **🪄 Micro-Interactions & Animations:** Engineered using Framer Motion for buttery smooth page transitions, scroll effects, and hover states.
- **📱 Fully Responsive:** Impeccable layout scaling across mobile, tablet, and high-resolution desktop viewports.
- **📨 Functional Contact Gateway:** Integrated with Web3Forms to capture client and recruiter messages directly to email.

## 🛠️ Technology Stack

| Architecture Layer | Technologies Utilized |

| **Language** | TypeScript (Strict Mode) |

## 🚀 Quick Start (Run Locally)

Want to clone and run this project on your local machine? Follow these steps:

**1. Clone the repository:**
```bash
git clone https://github.com/Rudrapratap0005/portfolio-website.git
cd portfolio-website
```

**2. Install dependencies:**
```bash
npm install
```

**3. Fire up the development server:**
```bash
npm run dev
```
Navigate to `http://localhost:5173/` to view the application live.

## 📂 Project Structure
